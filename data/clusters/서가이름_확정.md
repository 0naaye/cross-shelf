# 융합형 테마 서가 — 최종 확정 (2026-07-18)

책-책 함께대출 네트워크(coLoanBooks)에서 Louvain 커뮤니티 추출 → 안정적 클러스터 중
사전 선언한 기준(도서 8~20권 / KDC 대분류 3개+ / 허브편중 ≤0.5 / 내부굵기 ≥ 대상평균 0.248)을
통과한 **선정 3개** + 기준에 걸렸으나 주목할 **주목 2개**.

이름은 keywords(정보나루) + 구성책 + 부가기호(국가서지)를 근거로 후보 제시 → 사용자 확정.

## 선정 서가

### 1. 「아이와 함께 자라는 부모의 서가」 (클러스터 2, 14권)
- **이름 근거**: 키워드 `부모(6권)·아이(6권)·가족·감정·마음`, 부가기호 독자대상이 어른책 8권(실용3·교양3·청소년2) + 아이책 6권(아동)으로 **공존**하는 구조.
- **대표책**: 『나는 다정한 관찰자가 되기로 했다』(내부연결 1위·어른 양육태도), 『아이는 무엇으로 자라는가』(양육심리), 『고양이 해결사 깜냥』(아동 허브)
- **설명**: 부모가 육아·양육서를 빌리면서 아이에게 읽어줄 동화를 함께 빌린다. KDC로는 육아서(기술과학)와 동화(문학)가 완전히 다른 서가지만 실제 대출에서는 한 사람의 관심사로 묶인다. 독자대상으로 보면 어른책 8권과 아이책 6권이 공존하며 '감정·마음·공부'가 두 편을 잇는다. **KDC 분류 체계로는 만들 수 없는 서가.**
- **품질 3축**: 융합성 KDC 6개·교차 76% / 응집성 내부굵기 0.411(대상평균 1.7배)·밀도 0.23 / 검증 48%

### 2. 「위로가 필요한 날의 소설과 교양」 (클러스터 4, 11권)
- **이름 근거**: 키워드 `편의점(2권)·인생·사람`, 위로형 소설(『메리골드 마음 세탁소』·『달러구트 꿈 백화점』) + 쉬운 교양(『최소한의 세계사』). 부가기호 교양 100%·단행본 100%.
- **대표책**: 『요즘 어른을 위한 최소한의 세계사』/『최소한의 한국사』(내부연결 1·2위·쉬운 교양), 『불편한 편의점』(위로형 소설 대표)
- **설명**: 40대 독자가 위로를 주는 힐링 소설(편의점·꿈 백화점·서점 시리즈)과 부담 없는 교양(『최소한의 세계사』·『방구석 미술관』), 인생 담론서(『마흔 수업』)를 함께 빌린다. 전원 성인 교양 단행본이며 검증률 86%로 가장 단단하다.
- **품질 3축**: 융합성 KDC 4개·교차 48% / 응집성 내부굵기 0.27·밀도 0.527(최고) / 검증 86%(최고)

### 3. 「웃으며 읽는 어린이 교양」 (클러스터 5, 10권)
- **이름 근거**: 키워드 `만화(3권)·야구(69)·지식·정보`, 『흔한남매』(웃음) + 지식만화. 부가기호 아동 90%(형태는 만화 2·전집 6·단행본 2라 '만화' 대신 '교양'으로).
- **대표책**: 『축구 만화 도감』/『야구 만화 도감』(내부연결 1·2위·스포츠), 『흔한남매』(웃음·아동 허브), 『물리박사 김상욱의 수상한 연구실』(과학)
- **설명**: 아이들이 야구·축구 스포츠 지식과 과학·상식(『신기한 현상 사전』·『팩토피아』)을 재미있는 형태로 함께 읽는다. 독자대상 아동 90%로 균질하나 형태는 만화·전집·단행본이 섞여 '만화'보다 '재미있게 배우는 교양'이 정확하다.
- **품질 3축**: 융합성 KDC 5개·교차 67% / 응집성 내부굵기 0.351·밀도 0.27 / 검증 75%

## 주목 사례 (선정 기준 밖, 별도 보고)

### 「부와 성공, 나를 바꾸는 서가」 (클러스터 3, 13권) — KDC 2개로 탈락
- **근거**: 키워드 `부자·성공·투자·습관·금융`. 재테크서(돈의 속성·심리학) + 습관·성장서(아주 작은 습관의 힘·역행자).
- **의의**: 밀도 0.59로 **전체 1위**의 응집력이지만 KDC가 사회·철학 2개뿐이라 융합 기준(3개+)에 미달. **"융합을 기준으로 삼으면 오히려 가장 강한 단일 테마를 놓친다"는 방법론적 반례.**
- **품질 3축**: 융합성 KDC 2개·교차 24% / 응집성 내부굵기 0.34·밀도 0.59(1위) / 검증 57%

### 「인간과 삶을 응시하는 소설」 (클러스터 1, 21권) — 크기 초과로 탈락
- **근거**: 키워드 `인간·죽음·모순·한강`. 한강 5권(채식주의자·소년이 온다·작별하지 않는다·흰·희랍어 시간) 중심 + 최은영·클레어 키건.
- **의의**: 크기 21권으로 기준(≤20) 초과 자동 탈락. **2024 노벨문학상이라는 외부 이벤트가 만든 일시적 쏠림**. 인기 이벤트 클러스터의 사례.
- **품질 3축**: 융합성 KDC 6개·교차 60% / 응집성 내부굵기 0.236·밀도 0.26 / 검증 42% / 크기 21권(초과)
